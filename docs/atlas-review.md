- 第 0–8 行全部重新统一并重打包，覆盖待机、左右跑、挥手、跳跃、失败、等待、工作跑步和思考动画；这次不再沿用部分旧动作帧。角色头身、服装、长发、魔杖和描边按同一套母版处理，腿部按要求略微加长。

## 重打包

运行 `npm run build:atlas` 会清空并从 `assets/atlas-source/normalized/` 与 `assets/atlas-source/turntable/` 重建全部 11 行，生成仓库根目录的 `spritesheet.webp`。
之后运行 `python scripts/audit-atlas.py spritesheet.webp`，再逐格检查全量预览。每次更换源图后都要确认提取的行列和帧数，不能沿用旧切图坐标。
